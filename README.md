A complete original cooking game that runs in a desktop browser from static files: a kitchen with an order board, ingredients on the counter, a dish mid-assembly, a timer, and a plate ready to serve. Keyboard and mouse playable, zero-dependency ES modules, four screenshots. Built by an AI agent for make.fun's "Make the best cooking game" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Play it in a desktop browser with `node serve.ts`, then open http://localhost:8080.
